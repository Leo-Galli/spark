## Reporting a vulnerability

Please report security issues privately.

- Preferred: email [security@example.com] with subject `[PROJECT NAME] security`
- Or: use the host private vulnerability reporting feature if enabled for this repository

Do not open a public issue or discussion for a suspected vulnerability.

We aim to acknowledge private reports within [N] days.

## Scope

In scope for this project:

- [Example: unexpected network access from a tool documented as local-only]
- [Example: path handling that reads or writes outside the intended file]
- [Example: secrets or tokens committed by project tooling]

Out of scope:

- [Example: social engineering of maintainers]
- [Example: issues only in third-party dependencies with no project-specific exploit path -- report upstream when appropriate]
- [Example: denial-of-service against a local CLI with pathological input unless it is a documented guarantee]

## Safe harbor (optional short line)

We will not pursue legal action against good-faith reporters who follow this policy, avoid privacy violations, and give us a reasonable chance to fix before public disclosure.

## Preferenced disclosure

Coordinated disclosure is preferred. Public posts before acknowledgment may delay a careful fix.
